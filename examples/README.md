## 🎯 How to Use

### In the Web App
1. Start the Streamlit app: `streamlit run app/app.py`
2. Go to the "🎨 Examples" tab
3. Click "Predict" under any example image
4. View the predicted mechanical properties

### In Python Scripts
```python
from predict import load_model, predict_from_image

# Load model
model, scaler, meta = load_model()

# Predict from example
prediction = predict_from_image('examples/grid_high_density.png', model, scaler)
print(f"Predicted Young's Modulus: {prediction:.2f}")
```

### Run Demo
```bash
python demo.py
```

This will:

- Generate predictions for each
- Create a visualization (`demo_predictions.png`)
- Display summary statistics

## 🔬 Pattern Insights

### Why Different Predictions?

1. **Topology Type**: Different unit cell geometries (grid, honeycomb, gyroid) have inherently different mechanical properties

2. **Density**: Not always linear! Sometimes medium density performs better due to optimal load distribution

3. **Strut Arrangement**: 
   - Diagonal struts: Higher predicted modulus due to triangulated support
   - Honeycomb: Lower modulus but excellent energy absorption
   - Random: Variable performance depending on connectivity

4. **Scale Effects**: All examples normalized to 28x28 pixels to match training data
